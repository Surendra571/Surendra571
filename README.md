# 🧪 Engineering Principles

I try to build software that is:

* **Maintainable** — clear structure and separation of responsibilities
* **Testable** — automated unit and integration tests
* **Reliable** — validation and controlled failure handling
* **Scalable** — asynchronous processing where appropriate
* **Secure** — authorization and tenant isolation
* **Observable** — meaningful logs and predictable workflows
* **Practical** — solving a real problem instead of using AI just for the sake of AI
